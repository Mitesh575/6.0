01 What to Expect

  • Analyze Digital Evidence: Dissect forensic disk dumps, memory images, network PCAP logs, and hidden artifacts.
  • Identify the Attacker: Connect indicators of compromise (IOCs) and trace digital fingerprints back to the adversary.
  • Determine the Attack Method: Map out the complete kill-chain, ingress vectors, and lateral movements.
  • Find the Exploited Vulnerability: Pinpoint exact security loopholes and zero-day misconfigurations.
  • Solve within Time: Synthesize findings into a final case solution and debrief the jury before the timer runs out.

02 Investigation Rules

  • Squad Size: Exactly 2 to 3 members per registered investigation unit.
  • Event Coordinator: Dilli. Contact available on event day for briefing and lab allocations.
  • Permitted Tools: Wireshark, Autopsy, Volatility, CyberChef, Network Miner, Burp Suite & Python forensic scripts.
  • Evaluated on: Evidence Accuracy (30%), Threat Actor Identification (30%), Root Cause Analysis (25%), Submission Time (15%).
